Befehle und Tipps für Claude CodeSpickzettel für die Arbeit an den Apps auf dem Mac

So arbeitet das Team auf deinem Mac mit: Die Studio-Regeln gelten in jeder App, alle Teammitglieder stehen als Agenten bereit, und drei Befehle erledigen die wiederkehrenden Aufgaben. Tippe auf „Kopieren“ und füge den Befehl im Terminal oder in Claude Code ein.

Einmal einrichten

Im Terminal auf dem Mac. Holt das Studio-Kit und verknüpft Regeln, Agenten und Befehle mit Claude Code.

cd ~/Apps
git clone https://github.com/marcokland-web/DasTeam.git
bash ~/Apps/DasTeam/studio/installieren.sh

Danach Claude Code neu starten. Für die Freigabe-Prüfung braucht der Mac Node.js; fehlt es, sagt das Skript Bescheid.

Eine App auf die neuen Regeln umstellen

Im Terminal in den Ordner der App wechseln und Claude Code starten:

cd ~/Apps/BASE
claude

Dann in Claude Code eingeben:

/studio-umstellung

Nur einen Teil umstellen: /studio-umstellung icons, farben, texte oder pruefbericht. Reihenfolge der Apps: B.A.S.E, Gewohnheiten, Zählerstände.

Vor jeder Auslieferung prüfen 
/studio-freigabe

Prüft iPhone, iPad und Desktop in Hell und Dunkel, App-Icons, Manifest und Installierbarkeit. Ausgeliefert wird nur, was „freigegeben“ ist.

Wenn du einen Fehler findest oder Feedback gibst 
/studio-lektion

Claude Code schlägt vor, welcher Agent zuständig ist und welche Regel er lernt; du bestätigst. Direkt angeben geht auch:

/studio-lektion bug-bodo Beträge mit Tausenderpunkt immer mit 1.234 testen

Die Lektion landet im Gedächtnis des Agenten und im Eingang hier. Sag hier in Claude „Lektionen abholen“, dann übernimmt HR-Heidi sie in die Team-Seite.

Neues vom Team auf den Mac holen 
git -C ~/Apps/DasTeam pull && bash ~/Apps/DasTeam/studio/installieren.sh

Immer, wenn das Team dazugelernt hat oder jemand neu dazukommt, zum Beispiel nach der Teamleiter-Runde am Montag. /studio-umstellung holt sich den neuesten Stand auch selbst.

Das Team direkt ansprechen 
/agents

Zeigt alle Teammitglieder. Einzelne beauftragst du in normalen Worten, zum Beispiel:

  • „Lass design-doris die Kontoansicht auf iPhone, iPad und Desktop prüfen.“
  • „Bitte logo-luisa, das Icon-Set für Zählerstände zu erzeugen.“
  • „Lass bug-bodo und rant-randy die letzte Änderung prüfen.“
  • „hr-heidi soll eine Rolle für Barrierefreiheit vorschlagen.“ (eingestellt wird nur mit deiner Genehmigung)
Tipps und was du beachten musst
  • Nach jeder Umstellung das Home-Bildschirm-Icon einmal entfernen und neu hinzufügen, sonst zeigt das iPhone noch das alte Logo. Auf dem Desktop die App einmal neu installieren.
  • Vor größeren Umbauten lässt sich Claude Code erst einen Plan zeigen. Lies ihn kurz, bevor du „los“ sagst.
  • Jede App hat ihre eigene CLAUDE.md. Die Studio-Regeln gelten zusätzlich; bei Widerspruch gelten die Studio-Regeln, außer du sagst etwas anderes.
  • Fehlen die Agenten unter /agents: Claude Code neu starten, sonst das Installationsskript erneut ausführen.
  • Das Repository DasTeam ist öffentlich. In Lektionen keine Passwörter, Kontonummern oder persönlichen Daten schreiben.
  • Ausgeliefert wird nur nach bestandener /studio-freigabe.
So arbeiten wirIdeen, Personal, Teamleiter-Runde

Neue Ideen

  1. Die Teamleitung entwickelt mit ihrem Team Ideen, wie die Abteilung besser wird.
  2. Die Teamleiter-Runde stimmt sie über Abteilungsgrenzen ab.
  3. Marco entscheidet.
  4. Das Team setzt um und hält fest, was es gelernt hat.

Personal

  1. Die Teamleitung meldet Bedarf bei HR-Heidi.
  2. HR-Heidi schreibt das Rollenprofil und holt die Stellengenehmigung bei Marco ein.
  3. Nach der Genehmigung stellt HR-Heidi ein und stellt die neue Person vor.

Teamleiter-Runde

  1. Die vier Teamleitungen treffen sich jeden Montagmorgen.
  2. Sie berichten, was besser geworden ist, und verbessern die Zusammenarbeit.
  3. Neue Ideen und Ergebnisse landen hier auf der Seite und in der Chronik.

Team-Standards

  1. Desktop, iPad und iPhone prüfen. Fertig ist nur, was auf allen drei optimal aussieht: kein seitliches Scrollen, kein Zoomen.
  2. Das ganze Team einbeziehen. Prüfungen machen die zuständigen Fachleute.
  3. Das Logo wird mitentwickelt und sofort eingebaut.
  4. Jede App ist installierbar und zeigt auf iPhone und Desktop das richtige Logo.
  5. Vor jeder Auslieferung läuft die Freigabe-Prüfung.

Marke und DesignBrand-Portal: so sehen alle Apps aus

Alle Apps des Studios folgen einer Designsprache: Apple-Klarheit in Familienfarben. Bordeaux und Gold kommen aus dem Familienwappen, die klare Form, die Systemschrift und die Bedienung kommen von Apple. Verantwortlich ist Gestaltungs-Greta, die Icons zeichnet Logo-Luisa.

App-Icons
  • Bordeaux-Verlauf als Fläche, darauf ein goldenes Linien-Symbol. Keine Schrift, keine Schatten; einzige Ausnahme ist das „B“ von B.A.S.E.
  • Alle Apps teilen dieselben Farben und unterscheiden sich nur durch ihr Symbol.
  • Pflicht-Set je App: iPhone-Icon 180 px, Desktop 192 und 512 px, Android-Maske 512 px, Favicon 32 px.
  • Das Logo dieser Seite wächst mit: Jede Abteilung ist ein goldener Punkt in der Runde.
